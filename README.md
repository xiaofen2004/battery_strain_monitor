# 电池应变与电参数监测

用于锂离子电池充放电实验的 Windows 桌面绘图软件。选择应变仪和电池测试仪输出的数据文件，就能在同一时间轴上查看电池表面应变、电压和电流，并通过背景色对照充放电工步。软件以只读方式读取已保存的记录，可与正在运行的 Jupyter 采集程序配合使用。

## 软件功能

| 实验需求 | 软件支持 |
| --- | --- |
| 仅观察应变 | 从 20 个采集通道中任选 1～3 个，绘制应变随时间的变化 |
| 比较初值不同的测点 | 切换原始微应变和相对微应变 Δε，每个通道分别减去自己的首个有效值 |
| 关联电池工步 | 联合绘制应变、电压和电流，放电用浅红色、充电用浅绿色、搁置用浅灰色 |
| 对齐与降采样 | 按记录时间或各文件首点对齐，可调整时间偏移。应变支持自动判断 1 Hz / 100 Hz，也可手动指定，支持中值滤波、低通滤波和降采样 |
| 追踪与导出 | 手动或定时刷新到文件中最近一次保存的记录，可导出 CSV 数据和 PNG、PDF 图像 |

## 近期改进

- 增加多通道叠加与分通道子图。测点的应变范围差别较大时，每个子图可使用独立纵轴，缩放时共用时间轴。
- 增加高分辨率屏幕适配，可收起设置面板，为曲线留出更多空间。
- 支持构建 Windows x64 单文件 EXE。实验电脑只需复制并打开程序，运行环境已包含在内。

## 使用方法

1. **启动软件。** 仓库 `release/` 目录提供最新构建的免安装版 `BatteryStrainMonitor.exe`（校验值见同目录 `SHA256.txt`），将其放入可写文件夹并双击。使用本仓库源码时，按下方命令启动。
2. **选择模式和文件。** 在“仅应变–时间”模式选择应变仪文件。在“应变＋电压电流”模式另外选择电池工作簿。程序支持示例仪器以 `.xls` 为扩展名导出的制表符文本。
3. **设置通道与滤波。** 选择实际接线的通道、原始值或变化量，以及叠加或子图布局。应变采样率通常可选“自动”，输出频率应小于或等于输入频率。
4. **核对电池时间。** 默认优先使用表内总时间。只有工作簿每一行确实代表 0.01 秒时才选“固定 100 Hz 逐行重建”。若仪器以 100 Hz 采集、每秒只导出一行，应使用表内时间。
5. **绘图与更新。** 点击绘图按钮查看当前记录，持续观察时勾选“自动刷新”。若采集软件正在独占文件，请在其完成保存后刷新。

### 从源码运行

在 Windows PowerShell 中进入仓库目录，使用带 Tcl/Tk 的 64 位 Python 创建独立环境，然后启动程序。

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

在 VS Code 中打开仓库目录，选择 `.venv\Scripts\python.exe` 作为当前项目的解释器即可运行 `app.py`。依赖和版本范围见 [requirements.txt](requirements.txt)。

### 构建免安装 EXE

打包与日常运行共用 `.venv`，只需额外安装一次 PyInstaller：

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller==6.22.3
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_exe.ps1
```

构建成功后，脚本会在终端显示 EXE 的输出目录，默认为 `..\outputs\battery_strain_monitor_exe_当天日期`。同一天重复构建会覆盖该目录中的 EXE；需要保留时可用 `-OutputName` 指定其他文件夹名，例如 `.\build_exe.ps1 -OutputName battery_strain_monitor_exe_20261120_v2`。
